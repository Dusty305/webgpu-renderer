§4.4.4 Восстановление после потери устройства

Потеря устройства инициируется через Chrome DevTools → вкладка «GPU» → кнопка «Lose context». Модуль должен: остановить цикл рендеринга, сгенерировать событие webgpu-lost, сохранить последний кадр как статичное изображение.

Инструкция: 1. Нажмите «Создать элемент». 2. Откройте DevTools (F12) → вкладка Rendering или введите в консоли: document.getElementById("dl-el")?.dispatchEvent(new Event("webgpu-lost")) либо используйте chrome://gpu → «Force lose context». 3. Наблюдайте за событием webgpu-lost в логе.
