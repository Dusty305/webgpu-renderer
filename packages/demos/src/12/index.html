Запустите бенчмарк для просмотра результатов

* Пиковая память конфига B проецируется как RGBA8 ÷ 4 (соотношение BC7). Наведите курсор на ячейку «Формат» для реальных байт.
* Статус загрузки: ✓ done = полностью загружено, ⚠ OOM = GPU вне памяти, ⏱ timeout = превышено 60 с, ≈ streaming = потоковый конфиг.
* Измерение конфигов A/B - 120 кадров после загрузки; C/D/E - 300 потоковых кадров.
* PSNR/SSIM показывают позиции обзор / крупный план / средний план по сравнению с конфигом A (эталон). Конфиг A показывает ∞ дБ / 1.000.
* Перед захватом каждой позиции 20 разогревочных кадров позволяют менеджеру потоков адаптировать резидентность мипов к расстоянию камеры.
* Сходимость: первый кадр (и прошедшее время в мс), в котором все видимые текстуры удовлетворяют residentMip ≤ desiredMip + 1.
* Проявление: кадры, в которых любая видимая текстура изменила уровень мипа / всего кадров измерения.
