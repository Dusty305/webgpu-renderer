# @webgpu-streaming/texture-streaming

Модуль потоковой передачи текстур с управлением бюджетом для WebGPU. Прогрессивно загружает уровни мип-карт текстур в рамках настраиваемого бюджета памяти с вытеснением по алгоритму LRU.

Для тонкой настройки поведения стриминга использовать `configureStreaming()`.
